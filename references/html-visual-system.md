# HTML 视觉系统

生成或重做报告 HTML 时读取。本规范面向证据密集、表格与架构图较多的分析报告，目标是“冷静、清晰、可信”，不是营销页面。

## 1. 视觉方向

先声明一句视觉命题，至少包含读者、气质和主要阅读任务。例如：

> 面向产品与技术评审者的编辑式分析页，以高密度排版和克制色彩帮助快速定位结论、证据与风险。

默认采用：中性略带产品主色色温的底色、近黑正文、一个产品强调色、四个证据语义色、边框为主的层级、少量软阴影。不要默认使用紫色渐变、玻璃拟态、发光背景、装饰网格、巨型数字或等权卡片墙。

## 2. 设计令牌

所有颜色、字号、间距、圆角和阴影从令牌引用，避免逐元素手选。

```css
:root {
  color-scheme: light dark;
  --canvas: #f3f3ef;
  --surface: #fbfbf8;
  --surface-raised: #ffffff;
  --ink: #1d211f;
  --ink-2: #515955;
  --ink-3: #79817d;
  --rule: rgba(29, 33, 31, .12);
  --accent: #0f766e;
  --confirmed: #18794e;
  --inferred: #9a6700;
  --suggested: #175cd3;
  --unknown: #667085;
  --risk: #b42318;
  --space-1: .25rem;
  --space-2: .5rem;
  --space-3: .75rem;
  --space-4: 1rem;
  --space-6: 1.5rem;
  --space-8: 2rem;
  --space-12: 3rem;
  --radius-control: .55rem;
  --radius-panel: .9rem;
  --shadow-raised: 0 0 0 1px rgba(0,0,0,.04), 0 2px 7px rgba(0,0,0,.05);
}
```

按产品调整 `--accent` 和中性色温；证据语义色保持稳定。对比报告增加 `--product-a`、`--product-b`，两者亮度应接近，避免视觉上预设胜负。

## 3. 排版与密度

- 正文默认 16px，行高 1.7；说明、图例与证据元数据可用 13–14px。
- 标题只使用正文与强调两个字重；大标题收紧字距，不靠极粗字重制造层级。
- 中文正文行宽约 38–48 个汉字；摘要可更窄，表格和图占满内容区。
- 使用 8 / 16 / 32–48px 的三级间距节奏：组内、组间、章节间。
- 数字、证据 ID、提交哈希、字段名和代码使用等宽字体；普通正文不使用装饰性等宽字体。

## 4. 页面骨架

桌面端优先使用“窄侧栏目录 + 主内容”或“顶部摘要 + 横向可滚动目录 + 主内容”；移动端全部折叠为单列。报告正文是主工作面，不要把每个段落都包成卡片。

首屏必须回答：

1. 拆解对象是什么；
2. 证据截止到何时、来自哪里；
3. 最重要的结论是什么；
4. 如何进入详细章节。

章节默认使用留白和细分隔线。只有摘要、重要判断、风险或独立交互内容才使用带边界的面板。

## 5. 组件语义

### 证据标签

四类标签固定为“已确认、合理推断、建议设计、未知”。颜色不是唯一信号：标签必须同时显示文字，并在首次出现处提供定义。

### 表格

- 表头使用句式大小写/正常中文，不全大写，不换行。
- 使用横向行分隔，避免纵向网格和粗外框。
- 宽表格包在 `.table-scroll` 中；允许表格自身横向滚动，不允许整页横向滚动。
- 固定语义列可设置合理最小宽度；不要通过缩小正文到 12px 塞入一屏。
- 行首可用证据等级或对象色作 2–3px 辅助标记，但不能替代文字。

### 图表

- 每张图包含标题、目的句、图例和图后结论。
- 图负责关系，表负责字段和证据；不把 30 个节点塞进一张总图。
- Mermaid 容器可滚动；源码保留。CDN 失败时仍显示源码或等价文字摘要。

### 对比

- 同维度对象并列，并保持列宽、信息量和层级对称。
- 结论列使用中性色；仅对象名称和对象特有元素使用对象色。
- 优势/限制写清适用条件，不使用无依据的胜负分数。

### 导航与交互

- 目录使用文本链接；活动态通过字色和柔和背景表达，不改变字重。
- `:focus-visible` 必须清晰；锚点标题设置 `scroll-margin-top`。
- 复制、折叠、主题切换等控件具有 hover、focus、active 状态和可读标签。
- 尊重 `prefers-reduced-motion`；报告不需要滚动劫持或大幅入场动画。

## 6. 暗色与打印

暗色模式不是反色：保持同等文本对比，去除阴影，用表面亮度与细边界表达层级。所有标题使用统一浅色，不保留大面积品牌色面板。

打印样式至少做到：隐藏目录、悬浮按钮和交互控件；背景变为白色；文字为深色；避免章节标题孤立在页尾；表格允许跨页且重复表头；链接可保留可识别文本。用户需要 PDF 时查看打印预览。

## 7. 响应式与可访问性

- 页面宽度至少在 390px、768px、1440px 检查。
- 移动端正文不小于 16px，主标题可缩小；多列摘要与对比区改为单列。
- 长 URL、代码和标题可换行；表格与 Mermaid 单独滚动。
- 使用语义化 `header`、`nav`、`main`、`section`、`table`；图示给出文字结论。
- 正文、次要文字、状态标签和焦点环都需在实际背景上可辨认。

## 8. 反模板化检查

出现以下任意三项且没有内容理由时，先删减再美化：渐变 Hero、毛玻璃、辉光、装饰网格、重复卡片、巨型数字、过多圆角胶囊、假仪表盘、无证据 KPI、过多强调色。

最终逐项回答：每条边界、颜色、圆角、阴影和留白在帮助哪一种阅读判断？无法回答的视觉元素应删除或降级。

## 9. 基准模板

[report-template.html](../assets/report-template.html) 提供设计令牌、布局、证据标签、表格、Mermaid、暗色、响应式与打印样式。它是结构起点，不是固定品牌皮肤：应保留语义和质量门，并根据产品气质调整主色、标题和信息密度。
